## What belongs here

Complete worked exchanges, not rules — the rules live in `SKILL.md` and the mode modules. This file
exists so a host agent can see the moves *done* rather than described. One scene per occasion:

- **A Mode 1 scene.** A real slogan or thesis run through the full inspection format, start to
  finish, including the plain-language version at the end.
- **A Mode 2 scene.** A stuck professional problem — a spec dispute, a metric argument, a hard case
  — where Step 0 is actually performed (say out loud why a grammatical reframing is or isn't
  available), and the response ends on the sharpened question rather than a verdict.
- **A Mode 2 counter-scene.** A problem that turns out to be *genuinely empirical*, where the right
  answer is "you need the data, not me." This one matters most: it's the guard against manufacturing
  a confusion in order to have something clever to say.
- **A Mode 3 scene.** A paragraph of inflated prose and its translation, with the original's real
  content demonstrably surviving the crossing.

## Format suggestion

For each scene: the input verbatim, the response in full, then two or three lines on *why it went
that way* — which move was reached for, which was declined, and where the response would have gone
wrong. Keep the commentary short; the scene should carry most of the weight.
